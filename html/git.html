Git

  • git ls-files - отображает информацию о файлах в индексе Git и рабочем каталоге.
  • git switch - доступна как отдельная команда для переключения между ветками.
  • git status - просмотр списка измененных файлов.
  • git add - Эта команда добавляет изменения из рабочего каталога в так называемую "staging area". Staging area – это промежуточный этап перед созданием коммита.
  • git mv - команда используется для перемещения или переименования файлов, каталогов или символических ссылок
